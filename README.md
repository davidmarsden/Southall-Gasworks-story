# Southall Gasworks Story

Public evidence, methodology and publishing repository for the Southall Gasworks / Green Quarter investigation.

This repository is the **public layer** of a larger research project. The underlying investigation is conducted in a separate private evidence repository so that resident information, unpublished material, legally sensitive research and unverified machine extractions are not inadvertently published.

## What this repository is for

Over time this repository will provide:

- a transparent source catalogue for publishable evidence;
- reproducible public datasets derived from verified source material;
- timelines of remediation, monitoring, complaints, regulatory activity and decisions;
- maps and visualisations;
- pollutant and monitoring analyses;
- documented planning and regulatory requirements and what the evidence shows about their implementation;
- methodology explaining how documents and data were extracted, checked and analysed;
- evidence packs supporting published Southall Stories investigations;
- eventually, an interactive public evidence explorer.

## Publication principle

A claim should not appear here simply because an AI system extracted or inferred it.

The publication path is:

`private source → extraction → verification → analysis → editorial/privacy review → public evidence`

Published analytical claims should link as closely as practicable to the underlying primary evidence and state important uncertainty or limitations.

## What will not be published here

- personally identifying resident evidence without an explicit justification and appropriate consent/lawful basis;
- raw private correspondence merely because it has been ingested for research;
- unverified AI/OCR extraction presented as fact;
- speculative causal health claims;
- unsupported allegations of illegality or misconduct.

## Planned public sections

- `methodology/` — how the investigation works
- `sources/` — publishable source register
- `data/` — reviewed public datasets
- `timeline/` — machine-readable chronology
- `analysis/` — reproducible analyses and explanatory notes
- `evidence/` — publishable evidence packs
- `site/` — future public evidence explorer

## Status

Foundation stage. The private investigation is first building and testing the evidence/provenance system on a representative pilot corpus. Public datasets and findings will be promoted here only after that process is working reliably.
